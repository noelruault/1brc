§3  WHAT THIS FILE DELIBERATELY DOES NOT CONTAIN
==============================================================================

No timings. This report re-measures nothing: it is a distillation of measurements
already published in 07-experiment-ledger.md, and every figure it quotes is quoted
with the row that measured it. A retrospective that produced its own numbers would
be a new experiment wearing a retrospective's clothes, and it would need the quiet
window, the lock and the bracket that the ledger rows already paid for.

No taxonomy of the 18 review lines by defect kind. The obvious version (grep for
'correctness defect') classifies wrongly: go-opt-round-2-item13 ('the arm shipped
with its central guard unmutated') and go-opt-round-2-item14 ('the measurement held
twice and the code did not') are both code defects and neither line contains the
phrase. docs/1brc/lessons.md's standing rule is that a statistic over a set nobody
enumerated survives every arithmetic check, so the report quotes only the two counts
that are exact: 18 of 18 REPAIRED, and 15 of 18 lines containing the word 'published'.
