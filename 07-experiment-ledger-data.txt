-- 1. The secondary source, fetched -------------------------------------------

$ WebFetch https://github.com/karpathy/autoresearch   # 2026-09-01
What the README states, and only what it states: the agent "modifies the code, trains for 5 minutes,
checks if the result improved, keeps or discards, and repeats". The edited file is train.py, "the
single file the agent edits", holding the GPT model, the Muon+AdamW optimizer and the training loop.
Agent instructions live in program.md, and the user kicks a run off by pointing the agent at it. The
metric is val_bpb, "lower is better, and vocab-size-independent so architectural changes are fairly
compared". Training "always runs for exactly 5 minutes, regardless of your specific platform", which
the README prices at ~12 experiments/hour and "100 experiments while you sleep".
NOT stated in the README, and therefore NOT attributed to it in the ledger: how a hypothesis is
proposed, the numeric keep/kill threshold, and any rule about seeds, baselines or reproducibility.

The primary sources are in-repo and were read, not summarised from memory:
  shapes-image-file-format/AUTORESEARCH.md          (683 lines; mission, invariants, ranked queue, log)
